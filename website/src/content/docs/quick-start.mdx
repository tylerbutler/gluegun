To send your first GET request, open a Gun connection and wait until it is ready.
Then send the request and collect the full response in memory.

Before you start, [install Gluegun](/installation/)
and confirm that the package target is `erlang`. The installation page includes
the Hex dependency range and Git-development options.

## Key idea

Gluegun keeps connection setup and requests separate:

1. Open a connection to a host and port.
2. Wait until Gun reports the negotiated protocol.
3. Send requests with paths such as `/`, `/api/items`, or `/health`.
4. Close or shut down the connection when you are finished.

If you have a full URL, parse it with `gleam/uri` before you call Gluegun. Gluegun accepts only the separate host, port, transport, path, and query values.

Run the example from the repository root:

```sh
cd examples/basic_request
gleam run -m basic_request/guide
```

You should see `status: 200`, followed by the HTML response from `example.com`.

If the connection does not open or the request times out, use the
[troubleshooting guide](/advanced/troubleshooting/).

## Close the connection

The example owns the connection, so it calls `connection.terminate` before
returning a result. This releases the connection after success, a failed
exchange, or stalled connection setup. If both the exchange and cleanup fail,
it returns the exchange error. If only cleanup fails, it returns the cleanup error.

`terminate` is the strongest of three ways to stop a connection. It forces exit and flushes the caller's Gun messages, so it suits a stuck connection or deadline cleanup. `connection.close` stops the connection through Gun's supervisor, and `connection.shutdown` requests a graceful shutdown without waiting for exit. See [Message Flow](/advanced/message-flow/#close-and-shutdown).

## Timeouts

The example creates one `Timeout` with `connection.milliseconds(5000)` and
uses it for readiness and for the request. `milliseconds` validates its input,
so it returns a `Result` even for a literal value. Use `connection.infinity()`
to wait without a limit. The same `Timeout` type applies to connection
readiness, request bodies, and message receives.

For full module, type, and function details, use the [API reference](/reference/).
