Use TLS and put `Http2` before `Http1` to offer HTTP/2 first, with HTTP/1.1 as a fallback. The server selects the protocol and can use its own preference order.

## How fallback works

TLS ALPN (Application-Layer Protocol Negotiation) selects the protocol. Gluegun preserves your list order in the TLS ClientHello: `[Http2, Http1]` offers `h2` before `http/1.1`, and `[Http1, Http2]` offers `http/1.1` before `h2`. `connection.await_up` returns the protocol selected by the server. If the server supports only HTTP/1.1, Gun negotiates HTTP/1.1 and `await_up` returns `Http1`. With no explicit list, Gun's default protocols are unchanged.

Plain TCP (`connection.Tcp`) does not negotiate. Gluegun passes only the first
protocol in the list to Gun, with no fallback. This also applies when
`connection.Auto` selects TCP on a non-443 port without configured TLS options.
An explicit empty protocol list makes `connection.open` return `InvalidOptions`
before it starts a Gun process. Omit `with_protocols` to keep Gun's default.

## WebSocket note

You can use HTTP/2 for HTTP requests, but WebSocket connections require HTTP/1.1.
Keep a separate HTTP/1.1 connection for WebSockets. If you call
`websocket.upgrade` on an HTTP/2 connection, it returns `UnsupportedFeature`
and does not call Gun.

See the [connection reference](/reference/gluegun-connection/) for the full connection option API.
